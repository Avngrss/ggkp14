# WordPress для начинающих — простое объяснение

> Этот документ объясняет, как устроена будущая тема WordPress для сайта поликлиники. Написан простым языком для человека, который будет наполнять сайт, но не является программистом.

---

## Что такое тема WordPress?

**Тема** — это «внешний вид» сайта. Она определяет:
- как выглядят страницы (цвета, шрифты, расположение блоков)
- где находится меню, логотип, footer
- как отображаются новости

WordPress — это система управления сайтом. Вы заходите в **админку** (панель управления), редактируете текст, добавляете новости — а тема автоматически показывает это посетителям в красивом виде.

Наша новая тема будет называться, например, **ggkp14** и лежать в папке `wordpress-theme/`.

---

## Из чего состоит тема — простыми словами

Представьте сайт как конструктор из деталей:

```
┌─────────────────────────────────────┐
│  ШАПКА (header.php)                 │  ← Логотип, меню — на КАЖДОЙ странице
├─────────────────────────────────────┤
│                                     │
│  СОДЕРЖИМОЕ СТРАНИЦЫ                │  ← Меняется: главная, новость, «О нас»
│  (front-page.php / page.php /       │
│   single.php)                       │
│                                     │
├─────────────────────────────────────┤
│  ПОДВАЛ (footer.php)                │  ← Копирайт — на КАЖДОЙ странице
└─────────────────────────────────────┘
```

---

## header.php — Шапка сайта

**Что это:** верхняя часть сайта, которая одинакова на всех страницах.

**Что там будет:**
- Логотип поликлиники
- Главное меню (Главная, Прямые линии, Платные услуги…)
- Верхняя панель с быстрыми ссылками (Режим работы, Горячая линия…)
- Кнопка поиска
- Ссылка «Версия для слабовидящих»

**Кто редактирует:** меню — через админку (Внешний вид → Меню). Логотип — через Настройки → Идентичность сайта.

**Вам не нужно** открывать файл header.php — всё редактируется через админку.

---

## footer.php — Подвал сайта

**Что это:** нижняя часть сайта на каждой странице.

**Что там будет:**
- Текст «© ГУЗ «Гомельская городская клиническая поликлиника № 14»»
- Возможно, дополнительные ссылки

**Кто редактирует:** текст копирайта — через специальные настройки (ACF) или виджеты.

---

## front-page.php — Главная страница

**Что это:** шаблон именно для главной страницы сайта (https://ggkp14.by/).

**Что там будет:**
- Приветственный блок с названием поликлиники
- Быстрые ссылки (Запись к врачу, Электронные обращения…)
- Телефоны и контакты
- Блок «Структурные подразделения»
- Последние новости
- Полезные ссылки (баннеры партнёров)
- Боковая панель (поиск, время работы)

**Кто редактирует:** разные части — разными способами (см. ниже). Сам файл front-page.php трогать не нужно.

---

## page.php — Обычные страницы

**Что это:** шаблон для всех остальных страниц — «О нас», «Контакты», «Платные услуги» и т.д.

**Как работает:** вы создаёте страницу в админке (Страницы → Добавить), пишете текст — WordPress автоматически оборачивает его в красивый шаблон с шапкой и подвалом.

**Кто редактирует:** полностью через админку → Страницы.

---

## template-parts — Детали конструктора

**Что это:** маленькие кусочки шаблона, которые используются повторно.

Например:
- `hero-welcome.php` — приветственный блок на главной
- `news-section.php` — блок новостей
- `departments-grid.php` — сетка подразделений
- `sidebar-hours.php` — виджет «Время работы»

**Зачем:** один раз написали код блока новостей — он работает и на главной, и где угодно ещё.

**Вам не нужно** знать про template-parts — это для разработчика. Вам важно знать, **какой контент** в каком блоке редактируется.

---

## functions.php — «Мозг» темы

**Что это:** служебный файл, который:
- подключает стили (CSS) и скрипты (JS)
- регистрирует меню
- включает поддержку миниатюр, логотипа и т.д.

**Кто редактирует:** только разработчик. Администратор сайта этот файл не трогает.

---

## Где хранятся CSS-файлы (стили)

**Путь:** `wordpress-theme/assets/css/`

CSS определяет внешний вид: цвета, шрифты, отступы, размеры кнопок.

**Кто редактирует:** разработчик при обновлении дизайна. Администратор CSS не редактирует.

---

## Где хранятся JS-файлы (скрипты)

**Путь:** `wordpress-theme/assets/js/`

JS отвечает за интерактивность: мобильное меню, карусели, поиск.

**Кто редактирует:** только разработчик.

---

## Как редактировать меню

1. Войдите в админку WordPress
2. Перейдите: **Внешний вид → Меню**
3. Выберите нужное меню:
   - **Главное меню** — основная навигация
   - **Верхняя панель** — topbar
   - **Боковая панель** — sidebar links
4. Добавляйте страницы или произвольные ссылки
5. Перетаскивайте для изменения порядка
6. Для подменю — сдвиньте пункт чуть правее
7. Нажмите **Сохранить меню**

---

## Как добавлять новости

1. Войдите в админку
2. Перейдите: **Записи → Добавить новую**
3. Введите **заголовок** новости
4. Напишите **текст** в редакторе
5. Установите **изображение записи** (миниатюру) — справа в панели
6. Выберите **категорию** «Новости»
7. Нажмите **Опубликовать**

Новость автоматически появится в блоке «Последние новости» на главной странице.

---

## Как редактировать блоки главной страницы

На главной странице разные блоки редактируются по-разному:

| Блок | Как редактировать |
|------|-------------------|
| Меню навигации | Внешний вид → Меню |
| Новости | Записи → Добавить новую |
| Приветственный текст | Настройки главной (ACF) |
| Быстрые ссылки (Запись к врачу…) | Настройки главной (ACF) |
| Телефоны и контакты | Настройки главной (ACF) |
| Время работы | Настройки главной (ACF) |
| Структурные подразделения | Подразделения (отдельный раздел) |
| Полезные ссылки (баннеры) | Настройки главной (ACF) |
| Логотип | Настройки → Идентичность сайта |

---

## Что такое ACF?

**ACF (Advanced Custom Fields)** — это плагин WordPress, который добавляет удобные поля для редактирования.

**Простыми словами:** вместо того чтобы лезть в код, вы видите в админке понятную форму:

```
┌─────────────────────────────────┐
│ Настройки главной страницы      │
├─────────────────────────────────┤
│ Заголовок: [________________]   │
│ Подзаголовок: [______________]  │
│ Телефон горячей линии: [______] │
│                                 │
│ Быстрые ссылки:                 │
│  1. [Запись к врачу] [/url]     │
│  2. [Обращения]      [/url]     │
│  [+ Добавить]                   │
└─────────────────────────────────┘
```

**Зачем ACF нужен:**
- Администратор редактирует контент без программиста
- Поля понятно подписаны по-русски
- Можно добавлять/удалять элементы (ссылки, телефоны)
- Разработчик один раз настраивает поля — дальше работает редактор

---

## Почему ACF может быть полезен именно вам

1. **Не нужно знать HTML** — только заполнять поля
2. **Нельзя случайно сломать дизайн** — поля ограничены
3. **Быстрые ссылки** — добавили новую услугу за 1 минуту
4. **Телефоны** — изменили номер в одном месте, он обновился везде
5. **Полезные ссылки** — загрузили новый баннер через «Добавить изображение»

---

## Как понять финальную структуру темы

Думайте о теме как о **мебели в кабинете**:

| Элемент темы | Аналогия |
|--------------|----------|
| header.php | Дверь и табличка на входе (всегда на месте) |
| footer.php | Пол и ковёр (всегда на месте) |
| front-page.php | Специальная обстановка приёмной (главная) |
| page.php | Стандартная обстановка для других комнат |
| template-parts | Мебель: стол, стул, шкаф (переставляемые блоки) |
| functions.php | Электропроводка (невидима, но необходима) |
| CSS | Покраска стен и обои |
| JS | Выключатели и автоматика |
| Меню (WP Admin) | Указатели «куда идти» |
| Записи (Posts) | Газета с новостями (обновляется часто) |
| Страницы (Pages) | Справочник (меняется редко) |
| ACF | Анкеты для заполнения контента |

---

## Что вам нужно запомнить

1. **Новости** → Записи → Добавить новую
2. **Страницы** (О нас, Контакты) → Страницы → Редактировать
3. **Меню** → Внешний вид → Меню
4. **Блоки главной** (телефоны, ссылки, баннеры) → Настройки главной (ACF)
5. **Логотип** → Настройки → Идентичность сайта
6. **Не трогайте** файлы .php, .css, .js — это работа разработчика

---

## Если что-то пошло не так

- **Новость не появилась на главной** — проверьте, что опубликована (не черновик) и категория «Новости»
- **Меню не обновилось** — нажмите «Сохранить меню» и очистите кеш (если есть плагин кеширования)
- **Сломался дизайн** — не редактируйте код, обратитесь к разработчику
- **Нужна новая быстрая ссылка** — Настройки главной → Быстрые ссылки → Добавить
